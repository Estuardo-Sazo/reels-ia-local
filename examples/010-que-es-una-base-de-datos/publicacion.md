### Descripción
```
Cada vez que inicias sesión, compras algo en línea o le das me gusta a una foto, hay una base de datos trabajando detrás.
Hoy vamos a aprender qué es una y cómo funciona por dentro.

En este video:
📌 Qué es una base de datos: un sistema que guarda información de forma ordenada, para encontrarla, cambiarla y protegerla.
📌 Por qué no basta un archivo de texto o una hoja de Excel: con un millón de clientes habría que leerlo línea por línea, no sabe qué hacer si dos personas compran el último producto al mismo tiempo, y puede quedar a medias o dañado si se va la luz.
📌 Las dos partes por dentro: los datos, guardados en archivos en el disco, y el motor, el programa que los administra. Tú nunca tocas esos archivos: le pides al motor lo que necesitas.
📌 Tablas, filas y columnas: cada fila es un registro y cada columna, un dato de ese registro.
📌 SQL, el lenguaje para pedirle cosas al motor: "dame todos los clientes de Guatemala".
📌 Motores que vas a escuchar mucho: MySQL, PostgreSQL, SQLite y SQL Server.

Lo que resuelve una base de datos:
✅ Buscar rápido.
✅ Atender a muchos al mismo tiempo.
✅ No perder datos.

En el próximo video abrimos el disco para ver cómo se guardan de verdad tus datos.
Suscríbete para seguir aprendiendo cómo funciona la tecnología por dentro.

#BasesDeDatos #SQL #Programacion
```
